# Contact Directory

A modern Android application that tracks call logs, manages contacts, and provides quick response templates for incoming calls.

## Overview

**Contact Directory** is a feature-rich Kotlin-based Android application designed to enhance your contact management experience. It monitors incoming calls, maintains a comprehensive call history, stores custom response templates, and organizes your contacts efficiently—all in one intuitive app.

## Key Features

### Call Tracking
- **Real-time Call Monitoring**: Automatically tracks and logs all incoming and outgoing calls
- **Call History**: View detailed call logs with timestamps and contact information
- **Call Count Statistics**: Keep track of how many times you've called each contact
- **Foreground Service**: Runs as a foreground service to ensure reliable call tracking without interruption

### Contact Management
- **Contact Directory**: Browse and manage your phone contacts
- **Call Integration**: See call history for each contact
- **Quick Access**: Easy navigation to contact details
- **Synchronized Data**: Contacts sync with device phone book and app database

### Response Templates
- **Quick Responses**: Create and manage custom text response templates
- **Instant Replies**: Send pre-made response messages to incoming calls
- **Template Customization**: Edit and delete templates as needed
- **Storage**: All templates are saved locally in the database

### Settings & Customization
- **Permissions Management**: View and manage app permissions
- **Configuration Options**: Customize app behavior and preferences
- **Notifications**: Receive alerts for incoming calls
